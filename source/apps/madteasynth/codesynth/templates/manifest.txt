# Project-export template manifest:
#   dest-path-in-exported-project | source-path-from-repo-root | targets
# Targets: pebble, win32, microw8, wav (both wav targets), or `all`. Flags in
# the same column:
#   nofollow   don't walk this file's #includes
#   binary     carry byte for byte (no LF normalisation or include rewrite);
#              implies nofollow, excludes subst
#   subst      fill `{{NAME}}` placeholders at export time (ExportTemplateVar);
#              a subst entry with no placeholder is an error
# Only entry points go here: gen_template_embed.py walks the include graph, and
# a discovered file's mask is the union of its includers'. Discovered files keep
# their repo layout under src/c; only the shims' `../../../` includes are
# rewritten.
