
## Pebble - Build and install

Needs the Pebble SDK installed in WSL (Ubuntu), the phone on the same network
and the watch reachable from the phone's Developer Connection.

1. In the pebble app, enable Dev Connection
2. Update the value in `pebble_phone_ip.txt` with the value shown in the app
2. Run:

```bash
build_and_install.bat
```
